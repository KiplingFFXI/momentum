The bundled FF VII Save.mp3 and FF IX Moogle.mp3 sounds are from Final Fantasy VII
and Final Fantasy IX. These sound assets belong to Square Enix and are not covered
by Momentum's GPL license.

You can select your own .mp3 or .wav files from config/addons/momentum/sounds/.
Use that permanent folder for custom audio. Updates can replace this addon sounds
folder. Alerts shows the permanent location and has Copy sound folder path.
For an addon-folder custom sound, Copy to permanent folder keeps the original and
saves a copy with the same filename. It never overwrites an existing file.
Custom audio is user data. Addon updates must leave
config/addons/momentum/sounds/ untouched.
